# cruAIR — симулятор ПВО 6DOF

Инженерный симулятор перехвата «ЗРК vs ракета»: честная физика 6DOF + 3D-сцена.
Цель — **проверять заявленные ТТХ ракет перехватом** до начала стройки реальной системы ПВО.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 9 юнит/интеграционных тестов (физика + перехват)
npm run test:combat  # 8 тестов боя (залп, уклонение, дострел, 2 установки)
npm run test:robust  # Pk по 4 сценариям × 8 сидов
npm run build    # production-сборка в dist/
```

## Что внутри

**Физика (`src/sim/`, без зависимостей):**
- 6DOF: кватернионы (без gimbal lock), уравнения Эйлера, RK4, масса/центровка от выгорания через Isp
- Атмосфера ISA-1976, гравитация WGS84, ветер + порывы
- Аэродинамика табличная: Cx(M, alpha), dCL/dalpha(M), CMalpha(M)
- Автопилот: альфа-контур (PI по углу атаки) + feedforward + P по rate с шедулингом по qbar,
  приводы 2-го порядка с лимитами, удержание крена по вектору гравитации (без эйлеровых сингулярностей)
- Наведение: середина — доворот на упреждённую точку PIP по треку РЛС, финал — PN/APN
  со скоростью визирования по базе 100мс; ГСН с адаптивным лагом, РЛС 10Гц с альфа-бета фильтром
- Мультирейт: plant 2000Гц / управление 500Гц / наведение 100Гц; взрыватель на шаге планта
- Monte-Carlo: дисперсии ветра/тяги/шумов → Pk, медиана/P90 промаха

**Факт точности (seed-батч 8/8, ЗУР дальняя vs цель):**
| Цель | Pk |
|---|---|
| Встречная 700 м/с, 6км | 8/8 |
| Встречная + уклонение 10g | 8/8 (залп 2) |
| Weave 7g | 8/8 |
| Отворот 9g в финале | 7/8 (честно: тяжёлый манёвр) |
| Крылатая 250 м/с, 100м | 8/8 |
| **Искандер 2100 м/с + срывы 20g** | stock 0/8 → **дальняя+ 6/8** |

## Бой: установки, залп, уклонение

- **3 установки** (`SITES` в `config.ts`): Север-дальняя, Холм-средняя, Объект-ближняя —
  разные позиции и ракеты; режим «кооператив» ведёт бой всеми сразу.
- **Залп 1–3 + автоматический дострел** при промахе (лимит 6 пусков).
- **Цель уклоняется**: обнаружив ЗУР (дистанция настраивается), выполняет двухтональный
  weave + вертикальный джинк + отворот от пеленга. В HUD — «⚠ ЦЕЛЬ МАНЕВРИРУЕТ».
- **Искандер** (пресет в списке целей): квазибаллистика 2.1 км/с, ниже 20км —
  терминальные срывы 15–22g. Штатная дальняя его почти не берёт (честные 0/8) —
  зато установка «Север-2» с форсированным мотором (Isp 290 + маршевый участок) даёт 6/8.
  Выбор ввода под цель подставляется автоматически.
- Бой ~0.3–0.5с счёта, треки всех ЗУР пишутся и проигрываются в 3D.

## Живой бой за обе стороны + дальний обзор

- **Прорисовка до 130км**: террейн 160км, небо, туман; ромбики-маркеры ЗУР/цели видны сквозь всё.
- **Камеры атакующей стороны**: «Цель» (погоня) и «Нос цели» (от первого лица ракеты).
- **Играю за**: ПВО (авто-цель, классика) или Цель — живой бой в реальном времени,
  пилот: **W/S** набор/снижение, **A/D**/стрелки разворот; та же физика 6DOF,
  залп и дострел ПВО — автоматом. Скорость боя x1/x2/x4.

**3D (`src/three/`, Three.js):** террейн с холмами и плацдармом, небо-шейдер с солнцем,
ПУ/ТЭЛ, РЛС с вращающейся антенной, процедурные PBR-ракеты (не кубики), дым/шлейфы/взрыв,
камеры (орбита/сопровождение/камера ЗУР/РЛС), HUD телеметрии, графики, экспорт CSV.

## Как проверить свои ТТХ

1. Внеси данные в `src/sim/config.ts` (масса, тяга, таблицы Cx/Cl/Cm) — структура готова под любую ракету.
2. Поставь сценарий в левой панели → «Пуск ЗУР».
3. Справа «Запустить проверку» (Monte-Carlo 200 прогонов) → вердикт ЗАЯВЛЕННОЕ ДЕРЖИТ / ПОГРАНИЧНО / НЕ ДЕРЖИТ.
